# PRO-PAV — Website Showcase

Professional and responsive website developed for PRO-PAV, a company specializing in urban equipment maintenance, cleaning and sustainable urban services.

## Project Overview

The objective of this project was to design and develop a modern and responsive corporate website presenting PRO-PAV's services and providing visitors with an intuitive way to discover the company and request a quote.

## Main Features

- Modern and professional landing page
- Responsive design for desktop and mobile
- Services presentation
- Company presentation
- Quote request interface
- Contact information
- Responsive navigation menu
- Mobile-friendly user experience

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP

> The source code is kept private for client confidentiality.
